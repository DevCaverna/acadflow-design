# Política de Segurança — AcadFlow Design

Este repositório contém apenas especificações visuais, fluxos de produto e ativos estáticos (`SVG`, `PNG`, `.dc.html` e documentação Markdown), sem código executável de backend ou frontend.

## Como Reportar Problemas de Segurança

Caso identifique qualquer vazamento acidental de credenciais, informações sensíveis ou links internos indevidos neste repositório, **não abra uma issue pública**:

1. Utilize o recurso **Private Vulnerability Reporting** (Security Advisories) do repositório `DevCaverna/acadflow-design` no GitHub, caso habilitado, ou notifique os mantenedores da equipe **DevCaverna** por canal privado.
2. Para vulnerabilidades na aplicação executável, reporte diretamente em [acadflow-api](https://github.com/DevCaverna/acadflow-api) ou [acadflow-web](https://github.com/DevCaverna/acadflow-web).
