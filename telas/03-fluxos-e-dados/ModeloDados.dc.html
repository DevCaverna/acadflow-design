Modelo de dados · MVP
PostgreSQL 17 + TypeORM, 5 tabelas, migrations manuais (synchronize: false). Setas apontam para o lado “muitos”.
users
id uuid PK
name varchar(120)
email varchar(255) único*
password_hash bcrypt
role PROFESSOR | ALUNO
avatar_key text NULL
created/updated_at timestamptz
* único em lower(email)
disciplines
id uuid PK
code varchar(20)
name varchar(120)
description text NULL
semester varchar(7)
professor_id FK users
created/updated_at timestamptz
UNIQUE(code, semester)
activities
id uuid PK
discipline_id FK disciplines
title varchar(160)
description text NULL
due_at timestamptz NULL
created/updated_at timestamptz
sem status: publica ao criar
enrollments
student_id FK users
discipline_id FK disciplines
created_at timestamptz
PK (student_id, discipline_id) · seed
grades
id uuid PK
student_id FK users
activity_id FK activities
value numeric(3,1)
created/updated_at timestamptz
UNIQUE(activity_id, student_id) · 0–10
1 : N · leciona
1 : N · contém
1 : N · possui
1 : N · possui
1 : N · é aluno em
1 : N · recebe
Regras: FKs com RESTRICT (sem cascade silencioso de histórico). Sem nota = sem linha em grades, nunca 0. Papel e matrícula são validados no service. Timestamps em UTC, formatados no front. Notificações não têm tabela no MVP.
